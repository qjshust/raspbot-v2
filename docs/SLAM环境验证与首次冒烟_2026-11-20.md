## 3. 踩到的 5 个坑（都会在 WP-F 里再遇到，已修）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | `Failed to compute odom pose` 刷屏、`/map` 无发布者 | slam_toolbox 默认 `base_frame: base_footprint`，本项目契约用 `base_link` | 参数文件里显式 `base_frame: base_link` |
| 2 | 传了参数文件却不生效 | `online_async_launch.py` 的 launch 参数名是 **`slam_params_file`**，写 `params_file:=` 会被**静默忽略** | 用 `slam_params_file:=<绝对路径>` |
| 3 | `ros2 run` 直接起节点后 `/map` 一直没有 | slam_toolbox 是**生命周期节点**，裸跑停在 unconfigured 状态 | 用 launch（`autostart=true` 会自动 configure+activate），或手动 `ros2 lifecycle set` |
| 4 | 启动即两条 WARN：激光量程超出雷达能力 | 默认 `min_laser_range: 0.0` / `max_laser_range: 20.0`，C1 实际 0.2–15 m | 参数里改成 0.2 / 15.0 |
| 5 | 脚本 source `setup.bash` 直接退出 | 脚本开了 `set -u`，ROS 的 setup 脚本引用未定义变量 | 不要在 source ROS 的脚本里用 `set -u` |

另外两个操作层面的坑：
- `ros2 topic hz/echo` 在**没有发布者**时会一直等，`timeout` 发 SIGTERM 也可能被忽略 → 统一用 `timeout -s KILL`。
- PowerShell 把命令字符串传给 `ssh` 时会掉引号，`|`、`(` 之类会被远端 shell 误解析 → **复杂命令一律写成脚本文件再 scp 上去执行**。

## 5. 遗留问题（不阻塞，但要记账）

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | `/mnt/ssd` 挂载失败（`mnt-ssd.mount` failed，dmesg 两次 `uas_pre_reset: timed out`） | maps/bags 实际写在 SD 卡上；地图无所谓，录 bag 会磨损 SD | 先换线/换口；仍失败加 `usb-storage.quirks=0x21c4:0x0050:u`；最后手段只用 SD |
| 2 | 双网卡同网段：`eth0` .98 + `wlan0` .99，两条默认路由 | 手机端要固定用 .98；跨机 DDS 发现可能走错口 | 手机/网关固定用 .98；如要跨机调试再绑接口 |
| 3 | CPU governor = `ondemand` | Nav2 上来后控制周期抖动变大 | WP-H 里改 `performance`（systemd 或 cpufrequtils） |
| 4 | `vcgencmd` 打不开 `/dev/vcio` | 读不到 throttled/温度 | 用 `/sys/class/thermal/thermal_zone0/temp`，或加 sudo/udev 规则 |
| 5 | `imu_node` 收到 SIGTERM 时抛 `ExternalShutdownException`，被 launch 记为 `process has died`（exit code 1） | 关停日志难看，systemd 会把正常退出当失败；重启策略可能误触发 | `main()` 里 `try: rclpy.spin(node) except ExternalShutdownException: pass`，一行修复 |
| 6 | `slam_toolbox` 目录 `/tmp/slam_smoke.yaml` 是临时文件 | 重启即失效 | 正式参数应进 `raspbot_slam` 包的 `config/`，现在只是冒烟用 |

## 6. 下一步（按依赖顺序）

1. **WP-E 融合里程计**：`base_node` 现在直接发 `/odom` + `odom→base_link`，需按 v2.0 契约拆成 `/odom_raw`，由 `ekf_node` 发布唯一 `/odom` 与 TF。冒烟里的静态 TF 就是为了先验证 slam 通路，这一步完成后换掉。
2. **实测外参**：`base_link→laser` 现在是占位（0, 0.107, 0.034），装车后按 `mech/README.md §7.4` 用卷尺量，误差控制在 ±2 mm / ±0.5°。
3. **场地低速建图**：键盘/手柄遥控（`teleop_twist_keyboard`）以 0.12–0.15 m/s 绕场一圈，看 `/map` 是否闭合、有无重影——这是 M2 的真正验收，比任何静态测试都有价值。
4. 地图存取：`ros2 run nav2_map_server map_saver_cli -f /mnt/ssd/maps/<name>`（或 SD 卡上），再核对 AMCL 加载。
