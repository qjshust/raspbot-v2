      安全提示

      • 无轮编码器：odom 位姿会漂移，导航定位依赖 AMCL 激光修正；遥测显示「未定位」时禁止依赖走位精度。
      • 2D 雷达扫描面离地约 74 mm，看不见低矮/玻璃/镜面障碍，必须有人监护并限定场地。
      • 导航模式需先在地图上设置初始位姿，Nav2 才会激活；冷启动可能需要 20–60 s。
      • 急停按钮点击立即锁存；解除需要二次确认，解除前请确认机器人周围安全。
      • 断连时保留最后画面，遥控与危险操作会被禁用；恢复连接后自动刷新。
