# RASPBOT-V2 · HWT101 + 思岚 C1 安装件（设计说明 + 可打印模型）

> 目标：在不破坏车体、不改电路的前提下，给这台麦轮小车加装
> **维特智能 HWT101（串口陀螺仪）** 与 **思岚 RPLIDAR C1（2D 激光雷达）**，
> 做到「装得上、装得准、拆得下来、换件不用重做」。

```
mech/
├─ README.md                 ← 本文（设计思路、尺寸、BOM、装配、标定）
├─ build.py                  ← 参数化建模脚本（Blender 4.2 无头运行，导出 STL）
├─ render.py                 ← 渲染脚本（出图用，不影响打印）
├─ stl/
│   ├─ 01_lidar_shelf.stl       雷达前伸托盘（卡爪 + 通用八槽，适配 C1）
│   ├─ 02_imu_frame.stl         IMU 刚性转接板（树莓派 58×49 孔位）
│   ├─ 03_imu_carrier.stl       HWT101 减震载板（长槽 + 出线缺口）
│   └─ 04_lidar_riser_18mm.stl  可选 18mm 加高块
├─ render/                   ← 预览图
└─ work/                     ← 从 STEP 反推车体尺寸的分析脚本 + IMU 帧解析自检
```

## 1. 先给结论：为什么这样设计

| 需求 | 做法 | 为什么 |
|---|---|---|
| 不动车体、免打孔 | 雷达托盘用 **C 形卡爪夹住上层甲板前缘** | 甲板 2mm 厚，夹紧力足够托住 C1（约 200g）；拆装只要一把 M3 螺丝刀 |
| 换雷达不重做 | 安装面 8 条径向槽，**BCD 20–48mm** | C1 的 4 个底孔落在槽里就行；以后换 A1/LD19 也不用重画 |
| 雷达不挡视野 | C1 **整机前置**在甲板前缘之外 | 扫描面比车体高、比云台立柱低，前方 180° 全清（详见 §7.1） |
| IMU 要「准」 | HWT101 对 **水平度** 极敏感 | 它输出的是绕 Z 的角度，模块装歪 1°，航向就系统性偏 1° |
| IMU 要「稳」 | 刚性转接板 → 4 个硅胶减震柱 → 载板 | 厂家明确说「不适合强振动环境」，麦轮恰好振动大；减震是必须的，不是可选项 |
| IMU 在车辆中心 | 转接板用 **树莓派 4 个 M2.5 孔（58×49）** 定位 | 整车唯一「已知且精确」的孔位，装上自动对中 |

## 2. 基线数据

### 2.1 车体（从厂商 STEP 模型反推，单位 mm）

数据来源：`20.硬件资料\3D模型\raspbot v2麦轮版.STEP`。坐标系原点 = 上层甲板前缘中点，x 右、y 前、z 上，甲板顶面 z=0。

| 项目 | 数值 | 说明 |
|---|---|---|
| 整车（含轮） | ≈ 180 (x) × 160 (y) | 不含摄像头云台 |
| 上层甲板 | **90 × 170 × 2.0** | 黑色顶盖，前缘就是车头正面 |
| 甲板顶面距地 | ≈ 40 mm | 按模型估算，实测为准 |
| 树莓派 5 | 56 × 85，孔位 **58 × 49**（Ø2.7） | 派中心在甲板前缘后方 96.5mm |
| 摄像头云台立柱 | x ∈ [−8.5, +10.5]，y ∈ [−29, −16]，z **+26 … +80** | 雷达唯一的遮挡物 |
| 车体几何中心 | 甲板前缘后方 ≈ 77 mm | IMU 装在这里最理想 |

> ⚠️ 打印前用卡尺复核 3 个数：**甲板厚度**（默认 2.0）、**甲板宽度**（默认 90）、
> **前缘到云台立柱的距离**（默认 16mm）。不一致就改 `build.py` 里的 `PARAMS` 重新导出。

## 3. 零件与尺寸

### 01 雷达前伸托盘（适配 C1）

- 外形 **80 × 70 × 5 mm**，前伸到甲板前缘之外 **58mm**（C1 机体 55.6 见方，正好放下）
- 后部两个 **C 形卡爪**：槽高 3.4mm、咬入 8.8mm，兼容 **1.5–3.5mm** 厚甲板；每个卡爪一颗 M3×8 自攻从下方顶紧
- 安装面：8 条径向槽 3.4 × 12mm，**覆盖 BCD 20–48mm**；中心 **Ø22** 走线孔（C1 的 XH2.54 插头从这里下去）
- 两侧前角扎带孔 + 前缘中央 4mm 零位缺口
- C1 底座落在 z = 甲板 +9mm，扫描面约在甲板 **+34mm**

### 02 IMU 刚性转接板

- **62 × 70 × 5 mm** 平板，平放打印无需支撑
- 4 个 Ø2.7 沉头孔对准树莓派 **58×49**；4 个 Ø3.4 减震柱孔，间距 **22 × 18**
- 两条 3mm 长槽：走线 + 散热

### 03 HWT101 减震载板

- **48 × 40 × 4 mm**，4 个 **M3 沉头**（90° 锥形）减震柱孔 —— 螺钉头与板面齐平，模块能贴平
- 模块安装：4 条 **3.2 × 14 长槽**，默认按 30 × 28 孔距布置，**覆盖约 23–37mm 的孔距**；中间 26 × 20 是平面，留作双面胶区
- 前后各一个 **14 × 7 出线缺口**：弯针插头可以贴着板边出线，不会顶住模块
- 左前角两个小缺口 = **车头方向标记**；两侧扎带槽做线束应力释放

### 04 可选 18mm 加高块

- **62 × 44 × 18 mm**，可叠 2 块
- 用在：C1 底座与车头超声波/防撞条干涉时；或想让扫描面换个高度时

## 6. 装配

1. **先试装**：01 的卡爪从甲板前缘往后推到底，检查夹得住（能晃但不掉）。
2. 两颗 M3×8 自攻从下方顶紧，**分两次对角拧**，别一次拧死——2mm 甲板会裂。
3. C1 放上托盘，XH2.54 插头从 Ø22 孔穿下去，4 颗 M3 穿过径向槽固定。**先把 C1 的 0° 刻线对准托盘前缘缺口**，再拧紧；槽位留的余量正好微调角度。
4. 拆下树莓派 4 颗 M2.5 螺丝 → 装 12mm 尼龙柱 → 盖上 02 → M2.5×20 穿下去拧回车体铜柱（对角、分 3 次）。
5. 4 个减震柱拧到 02 上（下面 M3×8 盘头），再把 03 载板用 **M3 沉头**拧到减震柱上端（沉头必须拧到与板面齐平，否则 HWT101 贴不平）。
6. HWT101 固定：**有 4 个安装孔**就用 M3×8 穿过长槽；**没有孔（小尺寸模块常见）**就用 3M VHB 贴在中间平面，再从两侧扎带槽穿一根 2.5mm 扎带兜住做二次保险——胶在剪切方向非常硬，几十克的小模块完全够。**模块的 X 轴箭头指向车头**，并用水平泡/手机水平仪确认水平（这一步决定航向精度）。
7. 线束沿甲板边缘走，扎带固定在**远离电机线**的一侧；电机换向的 dV/dt 会串进 IMU 的串口，表现为角度偶发跳变。

### 6.1 HWT101 焊直针还是弯针？

**推荐弯针（90° 侧出）**，理由和条件如下：

- **弯针的力是「贴着板面」的**。HWT101 的精度来自内部陀螺的静止姿态，PCB 一旦受力微弯、或模块被线束拽出 0.1° 的形变，航向就会慢漂。直针 + 竖起来的杜邦头会形成一个约 15mm 的力臂，车一颠簸线束就在焊盘上反复加矩——这是这类模块最常见的故障。
- **高度低一半**。直针 + 杜邦头约 +14mm，弯针约 +7mm；03 载板上方还要走线、可能被云台或机壳压到。
- **走线顺**。弯针出线方向平行于板面，可以直接顺着载板边缘扎带固定，做应力释放最方便。

三个必须注意的前提：

1. **方向要在焊之前定**。弯针的出线方向是固定的：先假组装（模块放上载板、比一下线往哪边走），确认朝**车尾/甲板内侧**（远离云台），再动烙铁。
2. **弯针根部应力更集中**。插拔时的力直接作用在焊盘上，所以：用 **XH2.54 带锁扣的端子线**而不是裸杜邦；载板边上留 10–15mm 服务环，扎带固定；必要时点一点热熔胶。
3. **如果完全不打算再拆**（装在车上不会拔），**最好的其实是「不焊排针，直接焊线」**：4 根 26AWG 硅胶线穿过去焊死，最低、最抗振、没有插头质量。代价是不好拆，以及要用维特上位机改参数时得从线头接 USB-TTL。

> **例外是台架测试**：不装车、线束不受力，直针反而最省事（插拔方便、能直接接 USB-TTL 用维特上位机）。
> 等测试完、要装上车的时候再换弯针或直接焊线——`03` 载板上前后两个出线缺口就是给弯针留的，不用改件。

**接线（HWT101 → 树莓派 5 40-pin）**，注意 TX/RX 要交叉：

| HWT101 | 树莓派 5 | 说明 |
|---|---|---|
| VCC | pin 1 或 17（**3.3V**，推荐） | 模块 3.3–5.5V 均可；用 3.3V 可以保证逻辑电平就是 3.3V |
| GND | pin 6 | 共地 |
| TX | pin 10（GPIO15 / RXD） | 模块发→派收 |
| RX | pin 8（GPIO14 / TXD） | 派发→模块收 |

> 如果你坚持用 5V 供电（pin 2/4），上电前先量 TX 空闲电平：量到 5V 就串 1k/2k 分压再进派，别直接怼 GPIO。用 3.3V 就没这个问题。

## 7. 装完必须做的 4 项验证

### 7.1 扫描面有没有被挡

C1 扫描面在甲板 **+34mm** 左右，而云台立柱从 **+26mm 一直到 +80mm** —— **抬高雷达并不能绕开它**。
结果：正后方约 **±12°** 会被立柱挡住（22mm 宽物体在 50mm 距离上的张角）。对 2D SLAM 影响很小（建图主要用前方 270°），可以接受。

想彻底干净，三选一：**横向偏置**（托盘整体挪到一侧，立柱落到侧后方）｜**高塔**（扫描面抬到 +80 以上，重心变差，不推荐）｜**软件屏蔽**（`laser_filters` 切掉后向 ±15°）。

装完在 RViz 看 `/scan`：正前方 180° 应干净；若出现固定角度的短射线，先怀疑立柱，再怀疑 C1 的 0° 装反。

### 7.2 HWT101 接线与串口

```bash
# 1) 打开串口（config.txt 加 enable_uart=1；cmdline.txt 去掉 console=serial0,115200）
ls -l /dev/ttyAMA0
sudo usermod -aG dialout $USER     # 重新登录生效

# 2) 固定设备名
# /etc/udev/rules.d/99-raspbot.rules
SUBSYSTEM=="tty", KERNEL=="ttyAMA0", SYMLINK+="raspbot_imu"

# 3) 先看有没有数据（出厂 115200 8N1，模块直接发 0x55 开头的帧）
python3 -c "import serial; s=serial.Serial('/dev/ttyAMA0',115200); print(s.read(64).hex())"
```

- 有数据但全是 0 或乱码 → 波特率不对或没共地；一个字节都没有 → TX/RX 接反、或 `enable_uart` 没生效。正常应该看到 `55 51/52/53 ...` 反复出现。
- 波特率**出厂就是 115200**，和驱动默认值一致，不用改；只需用维特上位机把**输出速率从 10Hz 改到 100Hz**，否则 `/imu/data` 只有 10Hz，EKF 会抖。

### 7.3 装完的轴向与零位

- 模块的 **+Z 朝上、X 轴朝车头**。装反（Z 朝下）时角度符号会反，表现为「车往左转，航向往右走」。
- HWT101 的航向是相对的：上电位置即 0°（内部电池会记住上次的零位）。需要车头对准某个绝对方向时，用上位机做「角度归零」，或直接接受相对零点（SLAM 不需要绝对航向）。
- 如果模块与车头有 1–3° 的装配偏差，用 `yaw_offset_deg` 补偿，别指望 `angle_source` 能修。

### 7.4 TF 与外参

```bash
# base_link 在轴距中点（甲板前缘后方 77mm）
ros2 run tf2_ros static_transform_publisher \
  --x 0 --y 0.107 --z 0.034 --roll 0 --pitch 0 --yaw 0 \
  --frame-id base_link --child-frame-id laser_link
```

> C1 扫描面在甲板 +34mm；x/y 用卷尺量「base_link 标记点 → C1 旋转中心」再填，误差控制在 ±2mm / ±0.5°。

## 9. 已知限制

| 限制 | 影响 | 备选 |
|---|---|---|
| 前伸 58mm（车长 175 → 233mm） | 转弯半径略变、前伸部分先撞 | 缩短 `shelf_y1`；或把 C1 换成更小的 LD19 |
| C1 约 200g 压在卡爪上 | 长期振动可能微滑 | 卡爪与甲板间垫 0.5mm 双面胶；或甲板打 2 个 Ø3 孔改螺栓 |
| 扫描面固定 +34mm | 后向 ±12° 被云台立柱挡 | 横向偏置托盘 / 软件屏蔽（§7.1） |
| HWT101 怕振动 | 空转时角度可能抖 0.2–0.5° | 减震柱 + 走线应力释放 + 必要时 30Hz 低通 |
| 载板按 30×28 孔距预设 | 孔距不匹配时装不上 | 改 `imu_hole_dx/dy` 重导出；或直接用 VHB 粘在载板中央 |
